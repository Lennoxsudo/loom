对接逻辑建议

  1. 应用启动后走 checkForUpdates({ silent: true })，避免打断当前任务。
  2. 当 status=available 且版本未被忽略时弹窗；忽略记录建议用版本号 key。
  3. “立即更新”绑定 downloadAndInstall()，按 Started/Progress/Finished 驱动 UI。
  4. 进入 installing 后禁用主按钮，防止重复触发安装调用。
  5. status=error 时保留错误文本并提供“重试更新”。
