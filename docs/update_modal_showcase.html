⚙️ 软件更新处理逻辑架构 (AppUpdateModal Flow)

1. 启动静默检测

应用启动时根据 checkForUpdatesOnStartup 偏好在后台静默触发 checkForUpdates({ silent: true })，检测 GitHub Releases latest.json。

2. 发现更新弹窗

若检测到更高版本，status 转为 available，自动触发 AppUpdateModal 全局玻璃蒙层弹窗，展示版本号与 Release Notes。

3. 流式进度监听

用户点击“立即更新”后进入 downloading 状态，实时监听 chunkLength 字节流并动态推算下载百分比。

4. 安装与无缝重启

下载完成后自动解包安装（installing），状态变为 restartRequired，一键重启即刻体验新版本！
